# 2026-11-10 手动pid

在还没有用上 PID 光功率反馈的时候，我希望扫描激光失谐，同时保持光功率尽量一致。改变 AOM 的 RF 频率后，衍射效率也会变化，因此需要先测出**恒定光功率下，RF 驱动振幅与频率的关系**。这套软件就是为这件事做的。

电脑同时连接信号发生器和光功率计。软件逐点设置 RF 频率，根据实测光功率调整振幅，找到目标功率附近的 mVpp，并画出振幅—频率曲线、保存数据。测得的曲线可作为后续扫失谐时的振幅补偿参考。

“手动pid”是项目名称。软件执行的是逐点测量和参数搜索，不是实时高速 PID 光强锁定。

## 功能

- 设定目标光功率和允许误差；也可用已采集的入射参考功率计算衍射效率目标。
- 设定 RF 起止频率、频率步长、首点振幅估计与 RF 振幅上限。
- 自适应调幅与区间细化；后续频点沿用前一点的结果。基础步长可在扫描中修改并应用。
- 达不到目标时，保留经过复测的限幅最大值或局部峰值，并与达到目标的点区分显示；尚未确认的尝试保留为待补测记录。
- 同时显示全量程图、局部放大图和频点表；完成或停止后可打开完整数据表并另存 CSV。
- 自动保存逐点结果、每次采样记录及会话设置，支持载入旧测量、继续或补测。
- 显示 CH1 当前负载回读：高阻、50 Ω 或其他负载值；显示回读时间，支持空闲时刷新。
- 提供模拟仪器模式和离线数据查看模式。

## 环境与仪器

本项目在 Windows、64 位 Python 3.12 下验证。代码需要 Python 3.11 或更高版本，以及 Tkinter。

| 部件 | 当前支持 |
| --- | --- |
| 信号发生器 | RIGOL DG5352 Pro，CH1 正弦输出 |
| 光功率计 | Thorlabs PM100D、PM100D3、PM100USB，使用 TLPMX 驱动 |
| Python 依赖 | `pyvisa`，见 `requirements.txt` |
| 仪器驱动 | 可用的 VISA 后端及 Thorlabs 64 位 TLPMX 驱动 |

真实仪器模式默认从下面的位置加载厂商 DLL：

```text
C:\Program Files\IVI Foundation\VISA\Win64\Bin\TLPMX_64.dll
```

若驱动安装位置不同，修改 `devices.py` 中的 `TLPMX_DLL`。仓库不包含厂商 DLL；模拟和离线模式不需要连接仪器。

## 启动

在项目目录执行：

```powershell
python -m pip install -r requirements.txt
```

也可以双击 `install_dependencies.cmd` 安装 Python 依赖。VISA 和 Thorlabs 驱动需要另行安装。

| 用途 | 双击脚本 | 命令行 |
| --- | --- | --- |
| 连接真实仪器并测量 | `start.cmd` | `python app.py` |
| 使用模拟仪器预览 | `preview.cmd` | `python app.py --simulate` |
| 离线查看已有数据 | `offline.cmd` | `python app.py --offline` |

离线模式启动时不扫描 USB，也不自动连接或启动 RF；仍可通过界面主动选择连接仪器。

## 测量步骤

1. 在发生器与功率计之间完成光路、RF 和 USB 接线，确认外接负载与设备允许的振幅范围。
2. 在 UI 选择功率计，设置探头支持的校准波长，点“连接仪器（RF 关闭）”。
3. 输入目标功率、允许误差、扫频范围、首点估计、调幅步长及 RF 上限。
4. 点“新扫描”。界面实时显示进度、实测功率和振幅曲线。
5. 完成或停止后，点“查看 / 保存数据”打开完整表格，使用其中的保存按钮另存 CSV。
6. 如需恢复，点“载入测量”选择结果 CSV；程序会核对参数和仪器身份。“继续 / 补测”会跳过已完成频点。

改变光路、目标功率、入射功率或设备负载设定后，应重新确认原补偿曲线是否仍适用。图中横轴是 **RF 频率**；光学失谐与 RF 频率的对应还取决于光路的衍射级次和单程/双程配置。

## 负载设定与保护

**当前真实扫描会在启动时把 CH1 设为 50 Ω，并回读确认。** UI 的负载字段显示发生器的负载设定，不是测量外接电路的实际阻抗。“刷新负载”只读取设置，不改变负载、振幅或 RF 开关。

负载设置会影响仪器显示的振幅，应与实际接入负载相匹配。相关命令与语义见 [RIGOL DG5000 Pro 编程手册](https://download.rigol.com/en/Manual/Waveform%20Generator/DG5000%20Pro/DG5000Pro_ProgrammingGuide_EN.pdf)。

RF 振幅上限始终参与搜索约束。每次调节后至少等待 3 秒并检查采样稳定性；等待期间也检查光功率保护阈值。程序还包括过功率关断、功率回落确认、测量失败处理和退出时 RF 关闭确认。

软件保护受功率计采样和 USB 通信延迟限制，不能保证瞬时功率绝不过冲，也不能代替硬件保护。RF 上限与光功率关断阈值需要依据实际器件设置。

“上限内达不到目标”只针对本次已测振幅区间或确认的局部响应分支，不代表任意更高振幅都不可达。

## 数据文件

运行后，程序在本目录的 `measurements/` 下生成：

- `aom_equalizer_时间戳.csv`：每个频点的结果、振幅、功率、状态及测量条件。
- `aom_equalizer_时间戳_trials.csv`：调节过程中的采样明细。
- `aom_equalizer_时间戳.session.json`：本次设置、完成状态及续测来源。

保留三类文件便于恢复和追溯。载入测量时选择结果 CSV，不要选择 `_trials.csv`。导出的表格使用 UTF-8 BOM，便于 Excel 打开中文字段。

仓库保存程序与测试，不包含本机实验测量结果或设备序列号配置。`tests/fixtures/` 内的数据是人工构造的测试样例，不是实验测量。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `app.py` | Tkinter UI、扫描任务、图表及结果展示 |
| `scan.py` | 振幅搜索、采样、保护和续扫逻辑 |
| `instruments.py` | DG5352 Pro 回读验证、功率计量程管理、模拟适配器 |
| `devices.py` | VISA 与 TLPMX 基础设备访问 |
| `sessions.py` | 测量结果载入及会话保存 |
| `data_table.py` | 完整数据表与 CSV 另存 |
| `tests/` | 离线回归测试 |

## 测试

```powershell
python -m unittest discover -s tests -p "test_aom*.py"
```

测试使用模拟响应或替身，不需要打开 RF 或连接 USB 仪器。部分测试会创建隐藏的 Tk 窗口，因此需要支持 Tk 的桌面环境。
